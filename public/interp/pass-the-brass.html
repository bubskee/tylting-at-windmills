    Run and readout notes

    The answer margins come from the first of 200 held-out key stories. The original run saved the margins. For this peek we re-extracted the two residuals and refit the original eight-component bases on the same checkpoint, host, batches, and dictionary. ICA converged in eight iterations. The selected ICA and PCA directions reproduced the archived alignments with the means direction to six decimal places.

    The dictionary contains 64 paired stories each for keys, rooms, and passes. The default component per tool maximizes standardized brass/silver separation on 32 separate fit pairs. We center and scale each readout on the dictionary and orient its sign toward the silver fit mean. ICA reads with the pseudoinverse of the mixing directions. The lens uses the raw layer-7 state and the model’s vocabulary head, with bfloat16 logits. Close token ranks can tie at this precision.

    Layer numbers start at zero. The full patch copies the donor’s entire state at the final token of the first metal word. At this exact point the patched state equals the donor state. The question comes later. These plots inspect that pair of states. The recorded handoffs also let you try edits along individual tool directions.
