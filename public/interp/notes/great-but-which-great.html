Great, But Which Great?

Disambiguate the name

What does every other tool say?

Alexander and Catherine share the word “Great.” Borrow Catherine’s state there and the model still wants to begin its answer with “the.” Give it a choice between Macedonia and Russia and its preference flips. The first word would have hidden the interesting part.

Original walkthroughPatchscopes · Following Alexander the Great through the layersZoo experiment · saved rows

Published experiment. Patchscopes puts a source activation into a description prompt. The authors used descriptions from different layers to inspect how the identity of Alexander the Great emerges. Patchscopes entity-resolution walkthrough ↗

Proposed range test. Pair Alexander with Catherine the Great. Patch the state at the identical final token into the same receiver. At which layer can a blind reader match both descriptions to the right person? Include the receiver’s unpatched description. Proposed readout. put the raw vocabulary ranks beside the fluent description and find the first clue that distinguishes the two people.
